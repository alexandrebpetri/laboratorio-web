# Sprites

Este diretório mantém o spritesheet principal do jogo em `spritesheet.png`.

- `spritesheet.png`: atlas completo do conjunto visual do laboratório e dos personagens.
- `characters/`: organização para personagens e poses.
- `chemistry/`: itens químicos e de laboratório.
- `doors/`: portas, saídas e elementos de acesso.
- `props/`: objetos, móveis e elementos de cenário.
- `ui/`: interface e elementos visuais auxiliares.
