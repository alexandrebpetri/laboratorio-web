# src

Pasta principal da aplicação React.

Esta pasta reúne toda a estrutura do projeto que será usada para construir o jogo:

- `components/`: componentes visuais da interface e do gameplay
- `data/`: dados estáticos do jogo, como enigmas, salas e configurações
- `game/`: lógica central do estado e fluxo do jogo
- `hooks/`: hooks React para lógica reutilizável
- `styles/`: estilos globais e tokens visuais
- `utils/`: funções auxiliares e utilidades
- `App.jsx`: componente principal da aplicação
- `main.jsx`: ponto de entrada do React

A ideia desta pasta é manter o código organizado por responsabilidade para facilitar a evolução do jogo em etapas.
