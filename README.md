# Laboratório em Fuga

Jogo em React sobre fuga de um laboratório. O objetivo é resolver desafios, avançar pelas salas e escapar antes que o tempo acabe.

A estrutura também pode evoluir para um backend em JavaScript/ES6+, o que facilita a implementação de lógica do servidor e integração do jogo.

## Como rodar

```bash
yarn install
yarn dev
```

## Estrutura básica

- src/components: componentes visuais
- src/data: dados dos puzzles e salas
- src/game: lógica principal do jogo
- src/hooks: hooks do React
- src/styles: estilos globais
- public/assets: imagens, sons e sprites
